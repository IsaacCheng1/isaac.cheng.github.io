Chain of Thoughts

As LLM gets larger, the model shows emergent behavior - chain of thoughts. This is the key aspect of the reasoning/thinking model.

Alignment

Alignment is the problem of steering AI to align with the goal, values, and preference of humans. One way of alignment is fine-tuning.

Instruction Fine-tuning

A lot of data (with instructions such as translating this into French) are curated, e.g. chain of thoughts finetuning, or instruction finetuning which includes Q-A pairs.

RLHF

Reinforcement Learning from Human Feedback approximates a reward model with human preferences, then uses RL to finetune the LLM.

LLM to Agent

An agent is a system. It has a goal, a plan, and an environment which is used to get feedback. The agent uses LLM.

LLM to Agentic Workflow

Agentic workflow: LLM and tool orchestrates, through predefined code.

Agentic Workflow

It requires planning, multi-step reasoning, and self-improvement.

  • prompt chain
  • routing
  • parallelization e.g. deep research agent
  • orchestrator e.g. LLM manager doing planning
  • evaluator / judge
  • verifier e.g. verify the output of a coding agent. Verification is a hard problem. It can be one of the bottlenecks of agentic workflow.

Inference Scaling (Test Time Compute scaling)

  • One way to get more out of the model is inference scaling.
  • Repeated Sampling / Parallel Sampling: ask the model the same question multiple times → use a verifier to find a correct answer for the question.
  • Sequential Revision: ask the model to revise its own answers in sequence.
  • Reward Models
    • Outcome Reward Model to score the answer
    • Process Reward Model(PRM) score each step in model’s response
